# TicTacToe_ai
# Overview
This is a simple command-line Tic Tac Toe game implemented in Python, where the player competes against an AI opponent. The AI uses the Minimax algorithm to make optimal decisions, ensuring it never loses and often wins when possible.

# Features
Classic 3x3 Tic Tac Toe gameplay

Player vs AI mode

AI decision-making powered by the Minimax algorithm

Detects wins, losses, and draws

Clean and interactive terminal interface

# How It Works
The player chooses their symbol (X or O).

The board is displayed after every move.

The AI evaluates all possible outcomes using the Minimax algorithm to determine the best move.

The game ends when there is a winner or the board is full.
